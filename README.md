Vice Coast Cover Studio — an offline web app that turns any photo and a caption into GTA 6-style multi-panel poster cover art, exported as a PNG. Seven layouts (nine-panel grid, hero + three, four corners, full bleed, tilted snapshots, split duo, sunset strip), six sunset and neon colour grades, Anton display lettering with a Pacifico neon subtitle, a halftone title block, a star heat meter and a badge ribbon, per-panel crop and position, undo/redo, and exports in 1080 × 1080, 1080 × 1350, 1920 × 1080 and 1080 × 1920. Everything is original: no Rockstar Games logo, artwork or font.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — load a photo (or use the two built-in samples), pick a layout and a grade, edit the caption, click a panel to crop and position its photo, and export the PNG.
